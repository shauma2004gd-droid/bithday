Сайт для Кати ❤️

Что внутри:
- index.html
- 7 оригинальных фотографий (photo1.jpg ... photo7.jpg)

Как запустить:
1. Распакуй архив.
2. Открой index.html в браузере.
3. Для музыки положи свой файл `beliy-tanec.mp3` рядом с index.html.

Важно:
- Фотографии внутри Polaroid — это оригинальные файлы, они не генерируются заново.
- Фон затемнён отдельно, а рамка Polaroid затемнена ещё сильнее.
- Сердечки находятся за Polaroid.
- Тексты можно менять прямо в массиве `slides` в index.html.
